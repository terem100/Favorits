# 3ddd Tracker 📊

Аналитика спроса на 3D модели с сайта 3ddd.ru.
Показывает количество избранных, цены, рейтинги по разделам.

## Как это работает

```
GitHub Actions (ночью)          Cloudflare Worker
сканирует 3ddd.ru       →      проксирует картинки
сохраняет JSON данные          (твой IP не светится)
        ↓
GitHub Pages
красивый дашборд
```

## Установка — 5 шагов

### 1. Создай репозиторий на GitHub

- Зайди на github.com → "New repository"
- Назови его `3ddd-tracker`
- Сделай **приватным** (Private)
- Загрузи все файлы из этой папки

### 2. Включи GitHub Pages

- Репозиторий → Settings → Pages
- Source: выбери **"GitHub Actions"**
- Сохрани

### 3. Настрой Cloudflare Worker (для картинок)

1. Зайди на https://workers.cloudflare.com (бесплатная регистрация)
2. "Create a Worker"
3. Скопируй код из `worker/index.js`
4. Вставь в редактор, нажми "Save and Deploy"
5. Скопируй URL вида `https://xxx.workers.dev`
6. Открой `dashboard/config.js` и вставь URL в поле `workerUrl`

### 4. Запусти первое сканирование

- Репозиторий → Actions → "3ddd Scraper"
- Нажми "Run workflow"
- Подожди ~15-30 минут

### 5. Открой дашборд

После завершения сканирования и деплоя:
`https://ТВО_ЛОГИН.github.io/3ddd-tracker`

## Расписание

Сканирование запускается автоматически **каждую ночь в 6:00 по Москве**.

Чтобы запустить вручную:
- Actions → "3ddd Scraper" → "Run workflow"

## Настройки

В файле `scraper/scraper.js`:
```js
const CONFIG = {
  maxPages: 50,    // страниц на раздел (50 × ~20 = ~1000 моделей)
  delayMs: 1500,   // задержка между запросами (мс)
};
```

В файле `dashboard/config.js`:
```js
workerUrl: 'https://xxx.workers.dev',  // твой Cloudflare Worker
```

## Что собирает

По каждой модели:
- Название и URL
- Превью картинка (URL)
- Количество избранных ❤️
- Цена (0 = бесплатно)
- Тип (PRO / FREE)
- Рейтинг
- История изменений избранного (динамика)

По разделам:
- Мебель, Освещение, Декор, Санузел, Кухня
- Растения, Техника, Экстерьер, Другие модели
- Детская, Транспорт, Материалы, Текстуры

## Приватность

- ✅ Сканирование идёт с серверов GitHub (не твой IP)
- ✅ Картинки грузятся через Cloudflare (не твой IP)
- ✅ Данные хранятся в приватном репозитории
- ✅ Дашборд доступен только тебе (GitHub Pages можно сделать приватным с Pro планом)
